## 🚀 How to Use a Template

### Step 1: Choose Your Template
Pick the template that best fits your profile type (see guide above).

### Step 2: Copy the Template
Copy the entire content of your chosen template markdown file.

### Step 3: Customize with Your Details
Replace all `[PLACEHOLDERS]` with your actual information:
- `[YOUR NAME]` → Your actual name
- `[YOUR ROLE]` → Your job title
- `[YOUR TECH STACK]` → Your technologies
- `[YOUR USERNAME]` → Your GitHub username
- etc.

### Step 4: Use the Claude Prompt Generator
Rather than manually copying and pasting, you can:
1. Go to [`guides/index.html`](../guides/index.html)
2. Use the built-in prompt generator
3. Tell Claude which template to use as a base
4. Claude will customize it for you

### Step 5: Get Claude to Implement It
1. Use the generated prompt
2. Open Claude Chrome Extension on your GitHub profile
3. Paste the prompt
4. Watch Claude implement your profile

## 🎯 Customization Examples

### Example 1: Adding Your Tech Stack

**Find this in template:**
```markdown
### Languages & Frameworks
![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
```

**Customize by:**
1. Keep the format
2. Add your technologies
3. Use correct colors for each language
4. Find colors/logos at [shields.io](https://shields.io)

### Example 2: Updating Stats URLs

**Find this in template:**
```markdown
<img src="https://github-readme-stats.vercel.app/api?username=[USERNAME]&show_icons=true&theme=tokyonight"
```

**Customize by:**
1. Replace `[USERNAME]` with your GitHub username
2. Change `theme=tokyonight` to your preferred theme
3. Available themes: radical, merko, onedark, darkhub

### Example 3: Adding Your Social Links

**Find this in template:**
```markdown
[![LinkedIn](https://img.shields.io/badge/LinkedIn-0077B5?...)](https://linkedin.com/in/[YOUR-PROFILE])
```

**Customize by:**
1. Replace `[YOUR-PROFILE]` with your LinkedIn handle
2. Do the same for Twitter, Medium, YouTube, etc.
3. Keep or remove links you don't have
