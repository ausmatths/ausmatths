# GitHub Profile Template: Basic

A minimal, clean profile template perfect for beginners or those just getting started.

## Features
- Simple greeting
- Brief bio
- Core tech stack
- GitHub stats
- Call-to-action

## How to Use
1. Copy this template
2. Replace [PLACEHOLDERS] with your information
3. Paste into your GitHub profile README
4. Customize colors and sections as needed
