# Assets Directory

This directory contains visual assets, screenshots, and reference materials for the GitHub Profile Transformation System.

## 📁 Subdirectories

### `/screenshots/`
Step-by-step screenshots for each transformation step:
- `step1-chrome-extension.png` - Installing Claude Chrome Extension
- `step2-create-repo.png` - Creating profile repository
- `step3-customize-prompt.png` - Filling in your details
- `step4-paste-prompt.png` - Pasting prompt into Claude
- `step5-result.png` - Final transformed profile

### `/before-after/`
Comparison images showing transformation results:
- `before-empty-profile.png` - Empty profile (starting point)
- `after-transformed.png` - Fully transformed profile
- `profile-comparison.png` - Side-by-side comparison

### `/badges/`
Reference images and links for commonly used badges:
- Badge collection organized by category
- Logo references
- Color codes for consistency

## 🎯 Asset Guidelines

All screenshots should:
- Show clear, readable content
- Use 1920x1080 resolution (minimum)
- Have no personal information
- Be in PNG or JPG format
- Include labels or annotations if needed
