🔧 Install Claude Extension

If you don't have it installed:

  1. Open Google Chrome
  2. Go to Chrome Web Store
  3. Search for "Claude"
  4. Install the official extension by Anthropic
  5. Sign in with your Claude account
💡 Tip: Pin Claude to your toolbar by clicking the puzzle icon and pinning it.

📂 Create Profile Repository

Go to github.com and:

  1. Click the + button (top right)
  2. Select "New repository"
  3. Name it exactly like your username
  4. Make it PUBLIC
  5. Check "Add a README file"
  6. Click "Create repository"
⚠️ Repository name MUST match your username exactly (case-sensitive)!

✏️ Fill in Your Details

Go to the Prompt Generator on this page and fill in:

  • Your name
  • Your role/title
  • Years of experience
  • Your tech stack
  • Your social links (YouTube, Medium, LinkedIn)
💡 Use a text editor first to fill everything in, then copy the prompt.

⚙️ Paste & Let Claude Work

  1. Go to github.com/YOUR-USERNAME
  2. Click the Claude extension icon
  3. Paste the complete prompt (from the generator)
  4. Press Enter
  5. Sit back and watch Claude work!
✨ Claude will automatically edit your README in 1-2 minutes.

✅ Verify Your New Profile

  1. Go to github.com/YOUR-USERNAME
  2. Refresh the page
  3. See your transformed profile!

You should see:

  • ✨ Animated typing header
  • 👤 Professional about section
  • 🛠️ Tech stack badges
  • 📱 Social media links
  • 📊 GitHub stats cards
  • 🏆 GitHub trophies
