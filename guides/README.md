## 🚀 The 5-Step Process

### Step 1: Install Claude Chrome Extension
Install the Claude Chrome Extension from the Chrome Web Store and sign in.
**Time: 2 minutes**

### Step 2: Create Your GitHub Profile Repository
Create a repository named exactly like your GitHub username.
**Time: 1 minute**

### Step 3: Customize Your Details
Fill in your name, role, tech stack, and social links in the prompt template.
**Time: 2 minutes**

### Step 4: Paste Prompt & Watch
Paste the complete prompt into Claude and press Enter. Claude does the rest automatically.
**Time: 1 minute (Claude works for 1-2 minutes)**

### Step 5: Check Your New Profile
Refresh your GitHub profile and see your transformation!
**Time: 10 seconds**

**Total: ~6 minutes (most of it is Claude working)**

## 💡 Pro Tips

✨ **Use a text editor first** - Fill details in Notepad before pasting into Claude

✨ **Double-check URLs** - Verify YouTube, LinkedIn URLs before submitting

✨ **Be specific with tech** - Detailed tech stack = better badge generation

✨ **Accurate numbers** - Use current follower/subscriber counts

✨ **One complete prompt** - Send everything at once instead of multiple requests

✨ **Tell Claude everything** - The more specific you are, the better the result
