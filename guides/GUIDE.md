## Step 2: Create Your GitHub Profile Repository

GitHub has a special feature: if you create a repository with the **SAME NAME as your username**, the README.md of that repository becomes your profile page.

### Instructions:

1. **Go to GitHub**
   - [Open GitHub](https://github.com)
   - Log in to your GitHub account

2. **Check if profile repo already exists**
   - Go to: `github.com/YOUR-USERNAME/YOUR-USERNAME` (replace YOUR-USERNAME with your actual GitHub username)
   - If the repository exists, you are ready — skip to Step 3
   - If it says '404 Not Found', you need to create it

3. **Create the profile repository (if it does not exist)**
   - Click the '+' button (top right corner of GitHub)
   - Select 'New repository'
   - **Repository name:** type YOUR EXACT USERNAME (must match exactly)
   - Keep it **Public**
   - Check **'Add a README file'**
   - Click **'Create repository'**

GitHub will show a message: *"YOUR-USERNAME/YOUR-USERNAME is a special repository — its README.md will appear on your profile."* This confirms you did it correctly.

### ⚠️ Important:
- **The repository name MUST exactly match your username**
- If your username is 'jayanthbabu3', the repo name must be 'jayanthbabu3'
- Case sensitive

✅ Profile repository is ready. Now the magic begins.

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Claude is not opening my GitHub repo | Make sure you are on github.com when you open the Claude extension |
| Profile repo does not exist | Go back to Step 2 and create it. Repo name MUST match your username exactly |
| Badges are not showing | Refresh the page. Badges take a few seconds to load from shields.io |
| GitHub stats card shows wrong username | Tell Claude: 'Fix the username in stats cards to [your-username]' |
| Claude stopped in the middle | Type 'continue' and press Enter. Claude will resume from where it stopped |
| README looks broken | Tell Claude: 'The README has formatting issues. Please fix and save again' |
| Want different theme/colors | Tell Claude: 'Change theme to [dark/radical/tokyonight/merko]' |
| Want to add more sections | Tell Claude what to add. Example: 'Add a Recent Projects section' |
