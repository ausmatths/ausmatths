# Quick Reference Guide

One-page quick reference for the entire GitHub profile transformation process.

## ⚡ 60-Second Overview

| What | Details |
|------|---------|
| **Goal** | Transform an empty GitHub profile into a professional, impressive one |
| **Time** | 1 minute of clicking + watching Claude work |
| **Tools** | Google Chrome + Claude Chrome Extension + GitHub Account |
| **Cost** | FREE (everything) |
| **What You Get** | Animated header, about section, tech stack, social links, GitHub stats, trophies, visitor counter |

## 🚀 5-Step Process

```
STEP 1: Install Claude Extension (2 min)
   ↓
```

## 🎯 GitHub Repository Rules

✅ **DO:**
- Use your exact GitHub username for repository name
- Keep repository PUBLIC
- Include README.md file
- Use case-sensitive username (if your username is `JayanthBabu3`, don't use `jayanthbabu3`)

❌ **DON'T:**
- Use a different name for the repository
- Make it private
- Delete the README.md file
- Change the username case

## ⚠️ Common Issues & Fixes

| Problem | Fix |
|---------|-----|
| Badges not showing | Refresh page (wait 10 sec) |
| Claude stops mid-way | Type "continue" and press Enter |
| Wrong username in stats | Tell Claude "Fix username to [your-username]" |
| README formatting broken | Tell Claude to regenerate with proper formatting |
| Social links missing | Add them in a new prompt to Claude |
| Theme doesn't look right | Tell Claude "Change theme to [another-theme]" |
| Visitor counter not showing | Refresh page and try incognito mode |

## 💡 Pro Tips

✨ **Use Notepad first** - Copy prompt to Notepad, fill details there, then paste  
✨ **Double-check URLs** - Verify YouTube, LinkedIn, etc. URLs before pasting  
✨ **Be specific with tech** - More specific tech stack = better badges  
✨ **Accurate numbers** - Use current follower/subscriber counts  
✨ **No manual editing** - Let Claude do everything automatically  
✨ **Tell Claude everything** - One complete prompt > multiple small ones
